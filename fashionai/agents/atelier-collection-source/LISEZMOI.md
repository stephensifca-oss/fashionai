# Atelier Collection · Compact — version ChatGPT

## Installer le skill
1. Dans ChatGPT : Personnaliser → Skills → + → Créer un skill → Importer un skill (le libellé exact peut varier selon votre offre et votre espace de travail).
2. Importez le fichier `atelier-collection-compact-gpt.zip` tel quel, sans le décompresser.
3. Appelez-le dans une conversation avec `@atelier-collection-compact-gpt`, ou dites simplement « atelier collection ».

## Si les skills ne sont pas disponibles sur votre compte
Créez un GPT personnalisé : collez dans « Instructions » la section « Fonctionnement propre à ChatGPT » et le tableau du parcours de `SKILL.md`, ajoutez tous les fichiers du dossier dans « Connaissances », et activez « Génération d'images » et « Interpréteur de code ».

## Ce qu'il faut savoir
- Toutes les images sont générées dans ChatGPT, une à la fois, et consomment votre quota d'images (≈ 16 pour 8 looks).
- Gardez chaque fichier validé : vous les rejoindrez comme références (le skill vous dira lesquels, dans quel ordre).
- Aux points de passage, demandez « pack » : vous obtenez un .zip pour reprendre dans une conversation neuve.
